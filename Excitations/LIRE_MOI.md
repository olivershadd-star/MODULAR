# Excitations originales ANKS

Quatre sources synthetiques initiales; les huit ajouts de la V0.3 sont decrits dans NOUVELLES_EXCITATIONS.md; aucun enregistrement Technics. WAV mono, PCM 16 bits, 48 kHz, crete -6 dBFS environ.

Importer avec le bouton du plugin. Pour Lame_110Hz, regler RACINE sur 45; pour les autres, 60 constitue un point de depart de transposition, sans hauteur acoustique imposee. Le mode boucle relit tout le fichier : il ne garantit pas une boucle parfaitement continue.

- Impact_Sec.wav : 0.12 s, racine MIDI 60
- Souffle_Continu.wav : 1.0 s, racine MIDI 60
- Friction_Rugueuse.wav : 1.2 s, racine MIDI 60
- Lame_110Hz.wav : 0.8 s, racine MIDI 45
