MODULAR 1.4 ALPHA 2 — WINDOWS x64

Telecharger Modular-V1-4-Alpha-2-Windows dans les artifacts du workflow VST3 Windows,
puis extraire le ZIP Windows qui s'y trouve.

1. Fermer les hotes et sauvegarder une copie des projets existants.
2. Retirer l'ancien bundle du dossier VST3 scanne : le code du plugin reste Arlc,
   deux bundles avec la meme identite ne doivent pas cohabiter dans le scan.
3. Copier le dossier ENTIER Modular.vst3 dans C:\Program Files\Common Files\VST3\.
4. Relancer le scan et charger Modular sur une piste MIDI.
5. Pour l'application autonome, lancer Standalone/Modular.exe et choisir
   le pilote, le buffer et le peripherique MIDI dans les reglages audio/MIDI.

36 excitations integrees, aucune banque WAV a installer a cote.
Les anciens presets restent lisibles. Verifier les automations normalisees des
listes de types et d'ordre, et la restauration des projets dans votre hote.
Les emplacements A-F sont en serie ; glisser leurs en-tetes change l'ordre.
Le compteur Audio affiche le budget de calcul, pas les pertes du pilote.
